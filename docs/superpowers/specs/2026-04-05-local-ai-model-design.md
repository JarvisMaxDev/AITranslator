# Интеграция локальной AI-модели — Спецификация

## Контекст

AI Translator сейчас требует интернет для всех переводов (Anthropic, OpenAI, Gemini, Qwen — облачные API). Пользователям нужна возможность переводить офлайн — особенно EN<>RU — когда нет интернета. Решение должно быть гибким: пользователь выбирает модель под своё железо (RAM, диск) и ожидания по качеству.

## Подход

Встраиваем **llama.cpp** как движок инференса через SPM. Пользователи скачивают GGUF-модели (семейство Gemma — рекомендованное) и переводят полностью офлайн. Локальная модель становится ещё одним `AIProvider` в существующей архитектуре провайдеров.

## Архитектура

### Интеграция провайдера

`LocalModelProvider` реализует существующий протокол `AIProvider`:

```
AIProvider (protocol)
├── AnthropicProvider   (облако)
├── OpenAIProvider      (облако)
├── GeminiProvider      (облако)
├── QwenProvider        (облако)
└── LocalModelProvider  (НОВЫЙ — локальный инференс через llama.cpp)
```

**Файлы для модификации:**
- `AITranslator/Models/Provider.swift` — добавить `ProviderType.local`
- `AITranslator/Services/TranslationService.swift` — зарегистрировать LocalModelProvider
- `AITranslator/ViewModels/SettingsViewModel.swift` — состояние управления локальными моделями

**Новые файлы:**
- `AITranslator/Services/Providers/LocalModelProvider.swift` — реализация AIProvider
- `AITranslator/Services/LlamaInference.swift` — Swift-обёртка над llama.cpp
- `AITranslator/Services/ModelCatalog.swift` — каталог моделей + менеджер загрузок
- `AITranslator/Views/Settings/LocalModelSettingsView.swift` — UI управления моделями

### Интеграция llama.cpp

- Добавляем llama.cpp как SPM-зависимость (C-библиотека с Swift-бриджингом)
- Класс `LlamaInference` оборачивает: загрузку модели, генерацию текста, управление памятью
- Metal GPU ускорение на Apple Silicon (автоматически через llama.cpp)
- CPU fallback на Intel Mac

### Управление моделями

**Хранение:** `~/Library/Application Support/AITranslator/models/`

**Встроенный каталог (захардкожен, обновляется с релизами приложения):**

| Модель | Размер (Q4_K_M) | Качество | Языки |
|--------|-----------------|----------|-------|
| Gemma 3 1B | ~700 МБ | базовое | 140+ |
| Gemma 3 4B | ~2.5 ГБ | хорошее | 140+ |
| Gemma 3 12B | ~7 ГБ | отличное | 140+ |

**Кастомные модели:** Пользователь вводит имя модели на HuggingFace (например `unsloth/gemma-3-4b-it-GGUF`), приложение скачивает GGUF-файл с HuggingFace CDN.

**Состояния модели в UI:**
- Не скачана — кнопка "Скачать"
- Скачивается — прогресс-бар + кнопка отмены
- Скачана — кнопка "Удалить"
- Активна — визуально выделена как выбранная

**Фичи загрузки:**
- Прогресс-бар с процентами
- Поддержка отмены
- Возобновление при обрыве соединения
- Проверка целостности SHA256

**Жизненный цикл в памяти:**
- Модель загружается в RAM при первом запросе перевода
- Остаётся в RAM пока Local провайдер активен
- Выгружается при переключении на облачный провайдер
- Индикатор загрузки при инициализации (~2-5 сек)

### Инференс

**Промпт перевода:**
```
Translate the following text from {source_language} to {target_language}. Return only the translation:

{input_text}
```

**Параметры генерации:**
- `temperature: 0.1` — детерминированный вывод для точности перевода
- `max_tokens: адаптивно` — количество входных токенов x 1.5 (перевод может быть длиннее оригинала), ограничено контекстным окном модели
- Используются те же DTO `TranslationRequest`/`TranslationResponse` что и у облачных провайдеров

**Определение языка:** Существующий `NLLanguageRecognizer` определяет язык исходного текста (уже работает офлайн).

### Изменения UI

**Settings > секция "Local Model":**
- Список моделей из каталога со статусами (не скачана / скачана / активна)
- Кнопки Скачать/Удалить/Выбрать для каждой модели
- "Добавить с HuggingFace" — текстовое поле для имени модели, кнопка скачать
- Показан размер скачанной модели

**TranslatorView:**
- Local провайдер появляется в селекторе провайдеров как любой облачный
- Если модель не скачана — сообщение с просьбой скачать в Settings
- Индикатор загрузки при инициализации модели (первый инференс)
- В остальном — идентичный UX облачному переводу

### Обработка ошибок

- Модель не скачана → "Скачайте модель в Настройках для офлайн-перевода"
- Файл модели повреждён/отсутствует → предложение перескачать
- Недостаточно RAM → предупреждение с рекомендацией меньшей модели
- Ошибка инференса → стандартный AIProviderError с описанием

## Верификация

1. Собрать приложение с SPM-зависимостью llama.cpp — проверить чистую компиляцию
2. Скачать модель Gemma 3 1B из Settings UI — проверить прогресс-бар, завершение
3. Выбрать Local провайдер → перевести текст EN→RU — проверить корректный перевод
4. Отключить сеть → убедиться что перевод работает офлайн
5. Переключиться на облачный провайдер → проверить выгрузку модели из RAM (Activity Monitor)
6. Удалить скачанную модель из Settings → проверить удаление файла с диска
7. Добавить кастомную модель по имени HuggingFace → проверить скачивание и работу
8. Тест на Apple Silicon — проверить Metal GPU ускорение (быстрый инференс)
