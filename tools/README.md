# Проверка локальных моделей перевода

`benchmark-local-model.sh` компилирует **тот же** `LlamaInference` и `LocalTranslationPrompt`, которые использует приложение, с уже собранным пакетом [llama.swift](https://github.com/mattt/llama.swift). Отдельный сервер не нужен.

## Запуск

Сначала соберите Debug-конфигурацию приложения с выбранным `-derivedDataPath`. Затем:

```bash
bash tools/benchmark-local-model.sh \
  /absolute/path/to/DerivedData \
  "$HOME/Library/Application Support/AITranslator/models/gemma-4-E4B-it-Q4_0.gguf" \
  /absolute/path/to/results.json
```

Каждую модель запускайте отдельно, последовательно. Скрипт не скачивает модели и не меняет настройки приложения. Результат содержит исходные тексты, необработанные ответы, время каждого перевода, время загрузки и пиковый RSS процесса. Служебные каналы остаются в `rawOutput` намеренно; в приложении их удаляет `LocalModelProvider.cleanModelOutput`.

Набор `translation-samples.json`: 12 коротких примеров EN↔RU — переписка, технические термины, отрицания, идиомы, форматирование, имена и команды внутри переводимого текста. Перед замерами выполняется прогрев. Температура — 0, контекст — 4096; загрузка модели не входит во время перевода.

## Замеры 2026-11-14

Машина: M1 Max, 64 ГБ. Движок: [llama.cpp b10549](https://github.com/ggml-org/llama.cpp/releases/tag/b10549), пакет `2.10549.0`. Один проход по 12 примерам на модель, после обновления общего переводческого промпта.

| Модель | Медиана перевода | Пиковый RSS процесса |
|---|---:|---:|
| [Gemma 4 26B-A4B-it Q4_0](https://huggingface.co/ggml-org/gemma-4-26B-A4B-it-GGUF) | 0,933 с | 14,60 ГиБ |
| [Gemma 4 E4B-it Q4_0](https://huggingface.co/ggml-org/gemma-4-E4B-it-GGUF) | 0,840 с | 4,55 ГиБ |
| [Gemma 4 E4B-it Q8_0](https://huggingface.co/ggml-org/gemma-4-E4B-it-GGUF) | 1,023 с | 6,88 ГиБ |
| [Gemma 3 12B-it Q4_K_M](https://huggingface.co/ggml-org/gemma-3-12b-it-GGUF) | 2,059 с | 7,49 ГиБ |

**Вывод для этой машины:** 26B-A4B Q4 — предпочтительный баланс качества и скорости; E4B Q4 — экономичный вариант. В примере с «наступать на те же грабли» E4B переводила буквально, а 26B передала смысл как повторение ошибок. У Q8 на этом наборе не обнаружено убедительного преимущества над Q4. Старшая Gemma 3 добавила стихотворение в тесте, где команду о стихотворении следовало только перевести; Gemma 4 с общим обновлённым промптом перевела текст как текст.

Это ручная оценка небольшого синтетического набора, не универсальный рейтинг качества. RSS — показание процесса, не полный замер всех GPU-аллокаций. Время первого запуска зависит от файлового и шейдерного кеша и напрямую между этими запусками не сравнивается.
